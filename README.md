# Kaspi Hub

Локальная панель продавца Kaspi: заказы, товары, склад, прайс-лист с прибылью и рекламой, упаковка с накладными одним PDF.
Python (без фреймворков) + SQLite + одна HTML-страница.

## Возможности
- **Главная**: заказы за сегодня, выручка, график по часам, рекомендации, здоровье склада, товары сегодня (топ 5 + «Больше»)
- **Аналитика, Заказы, Товары**: периоды, поиск, возвраты и отмены считаются отдельно от выручки
- **Склад**: остатки из `ACTIVE.xlsx` (выгрузка прайс-листа из кабинета Kaspi), скорость продаж, дефицит
- **Прайс-лист**: себестоимость, комиссия, налог, прибыль, маржа, показы, CTR, CR, реклама, ДРР, чистая маржа; выгрузка в CSV
- **Маркетинг**: расходы и статистика рекламы (вручную или файлом xlsx/csv)
- **Упаковка**: одна кнопка собирает заказы в Kaspi и склеивает накладные в один PDF, одинаковые товары подряд
- **Журнал действий**, ежедневные резервные копии базы, доступ с телефона

## Установка
```bash
python3 -m pip install -r requirements.txt
```
Нужен Python 3.9+.

## Запуск
```bash
export KASPI_TOKEN="ваш_токен"
python3 server.py
```
Открыть: http://localhost:8000

Доступ с телефона (тот же Wi-Fi), пароль обязателен:
```bash
HOST=0.0.0.0 HUB_PASSWORD="длинный_пароль" python3 server.py
```
Остальные переменные: см. `.env.example`.

## Склад
Положите рядом с `server.py` файл `ACTIVE.xlsx` (Товары -> Прайс-лист -> Скачать в кабинете Kaspi). Сервер подхватывает новый файл сам.
Kaspi API остатки не отдаёт, поэтому обновлять файл нужно вручную.

## Упаковка и накладные
Кнопка **меняет данные в Kaspi**: заказы помечаются собранными, это необратимо. Для первой пробы:
```bash
PACK_LIMIT=2 python3 server.py
```

## Безопасность
- Токен хранится только в переменной окружения, в коде его нет.
- `hub.db` содержит данные покупателей (имена, города): не публиковать (уже в `.gitignore`).
- Репозиторий держите **приватным**.
- Сервер вне localhost без пароля не запускается; POST-запросы принимаются только с того же адреса.

## Ограничения Kaspi API
- нет остатков, статистики рекламы (показы/клики), причин возвратов и комиссий по заказам: эти данные вносятся вручную или файлом;
- Kaspi часто отдаёт в позиции заказа категорию вместо названия: товары сопоставляются со складом по SKU.

## Структура
